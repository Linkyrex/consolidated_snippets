# Automation Scripts Collection

This repository contains a collection of versatile automation scripts implemented in Shell and Python to help with common DevOps, cloud, monitoring, data-processing, and codebase maintenance tasks.

## Contents

- `ci_helpers.sh` - Utility functions for CI/CD pipelines.
- `monitor_disk_usage.py` - Monitor disk usage and send alerts.
- `deploy_app.sh` - Simplify cloud app deployment.
- `process_logs.py` - Parse and process server logs.
- `cleanup_temp_files.sh` - Remove temp files regularly.

## Usage

Each script includes usage information and can be run standalone. Feel free to modify as needed.
